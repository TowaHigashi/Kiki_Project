# 開発ルール

## 1. 言語・構成

- 言語は **JavaScript**（TypeScript は未採用）
- Vue は `<script setup>` を用いる
- ルータ（vue-router）は使用しない。画面切替は Store のフラグで表現する

## 2. 責務の境界

| 層 | 置いてよいこと | 置いてはいけないこと |
|----|----------------|----------------------|
| `components/three` / composables | 描画・カメラ・Raycaster・演出・アセット読込進捗通知 | モーダル文言の組み立て |
| `components/ui` / `modal` | UI 表示・ボタン・ローディング / ナビ / サウンド UI | Three.js のシーン生成 |
| `stores` | 共有状態 | 重い描画ロジック |
| `data` | 静的設定（オブジェクト定義・遷移マップ・インタラクション種別） | 実行時の副作用 |

Three.js と Vue を直接つなぐ場合は、必ず **Pinia（sceneStore）** を介す。

## 3. データ追加の手順（作品・オブジェクト）

1. `src/data/objects.js` にエントリを追加する（`id` は config=`1xxx`、クリック対象=`2xxx`、装飾モデル=`21xx`）
2. クリックで寄らせる場合は `cameraFocusIn` / `cameraFocusOut` を埋める
3. インタラクション種別がある場合はデータ側のアクション定義を設定する（詳細は `34_データ設計.md`。現状フィールドは拡張予定）
4. モーダル左右移動が必要なら `src/data/modalComponentMap.js` を更新する
5. 詳細パネルが必要なら `components/modal/` に Vue を追加し、`ObjectInfoPanel.vue` の `switch` に紐づける
6. `SceneCanvas.vue` で `SceneObject` を配置する（将来は `v-for` 化予定）
7. 新規アセットはローディング対象に含め、読込完了ゲート（要件 5.8）と矛盾しないようにする

**Three.js のコア実装を直接いじらず、データとパネル追加で拡張することを原則とする。**

## 4. Store の扱い

- Store は現状 `sceneStore` のみ
- 状態の更新は各モジュールから直接代入してよい（setup store の `ref` を公開している）
- 新しい共有フラグ（ローディング進捗、スタート可否、ナビ表示など）が必要になったら、まず Store に追加し、UI / Three 側は Store を監視する

## 5. 命名・ファイル

- コンポーネントは PascalCase（例: `SceneCanvas.vue`）
- composable は `useXxx.js`
- データ定義は `objects.js` / `modalComponentMap.js`（`.ts` ではない）
- テスト・廃止予定ファイル（`*test.vue`、`CameraController.js` など）は新規参照しない。削除 TODO があれば優先して片付ける
