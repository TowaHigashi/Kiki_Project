# 要件定義

## 1. 背景

従来のポートフォリオサイトは、作品を一覧形式で掲載する構成が一般的である。
しかし、その形式では制作者の世界観や作品同士のつながり、作品を体験する流れを十分に表現することが難しい。

本プロジェクトでは、作品を「閲覧する」のではなく「探索する」体験を提供することを目的とし、3D空間を活用したポートフォリオサイトを構築する。

---

## 2. 目的

ユーザーが3D空間を自由に探索しながら作品を閲覧できるポートフォリオサイトを提供する。

また、作品情報だけでなく、空間・演出・BGMなどを含めた体験を通して、制作者の世界観を効果的に伝えることを目的とする。

---

## 3. 利用者

本システムの利用者は以下を想定する。

- 紀紀のリスナー
- 初見の訪問者
- 音楽関係者
- クライアント・企業担当者

---

## 4. 利用シナリオ

利用者は以下の流れで本システムを利用する。

1. サイトへアクセスする
2. アセットの読み込み状況を確認する
3. スタート画面を表示する
4. 3D空間を探索する
5. 気になったオブジェクトを選択する
6. 作品・情報を閲覧する（モーダル等）
7. 必要に応じてメニュー・ヘルプ・設定を利用する
8. 3D空間へ戻る
9. 他の作品を探索する

---

## 5. 機能要件

本システムは以下の機能を提供する。

責務の分け方:

- **作品閲覧 / 外部連携** … 何を見せるか・どこへつなぐか
- **インタラクション / カメラ / 演出 / サウンド** … 空間内の体験・表現
- **UI / 設定 / ナビゲーション / ローディング** … 操作面・設定・導線



### 5.1 探索機能

- 3D空間を自由に探索できる
- ユーザー操作によって視点を変更できる



### 5.2 作品閲覧機能

- オブジェクトを選択できる
- 選択した作品の詳細情報を閲覧できる
- 動画を閲覧できる
- 外部サイトへ遷移できる

※ 詳細の表示枠（モーダル）自体は 5.10 UI 機能に定義する。

### 5.3 サウンド機能

- BGMを再生できる
- 環境音を再生できる

※ 状況に応じた BGM 切替は 5.9 演出機能、ON/OFF・音量は 5.11 設定機能に定義する。

### 5.4 外部連携機能

- SNSへ遷移できる



### 5.5 インタラクション機能

- オブジェクトに対してインタラクションできる
- オブジェクトごとに異なる動作を実行できる

※ オブジェクトに応じた演出の再生は 5.9 演出機能に定義する。

### 5.6 カメラ機能

- オブジェクトへ自動的に視点を移動できる
- 初期位置（スタート地点）へ戻ることができる
- カメラ演出を再生できる



### 5.7 ナビゲーション機能

- 探索を補助する情報を表示できる

※ 操作方法の確認（ヘルプ）は 5.10 UI 機能に定義する。スタート地点へのカメラ復帰は 5.6 に定義する。

### 5.8 ローディング機能

- アセットの読み込み状況を表示できる
- 読み込み完了後に探索を開始できる



### 5.9 演出機能

- 時間経過による演出を行える
- オブジェクトに応じた演出を再生できる
- BGMを状況に応じて変更できる
- 空間演出を再生できる



### 5.10 UI機能

- メニューを表示できる
- 設定画面を表示できる
- クレジットを表示できる
- ヘルプを表示できる
- モーダル画面を表示できる



### 5.11 設定機能

- BGMのON/OFFを切り替えられる
- 音量を変更できる
- フルスクリーンを切り替えられる

※ 設定項目の変更 UI は 5.10（設定画面・音量調整）から提供する。

---



## 6. 非機能要件



### 6.1 動作環境

- PCブラウザで快適に動作する
- スマートフォンブラウザで利用できる
- 主要ブラウザに対応する



### 6.2 パフォーマンス

- 初回ロード時間は7秒以内を目標とする
- 描画性能は60FPSを目標とする



### 6.3 保守性

- 新しい作品を追加しやすい構成であること
- 保守・拡張が容易な構成であること

---
