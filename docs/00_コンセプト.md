# コンセプト

## プロダクト名

**Layered puzzle**

紀紀の世界観を、3D 空間の探索として体験するポートフォリオ。

## 一言で言うと

3D空間を「探索」しながら、紀紀の作品・演出・音を層（Layer）として重ね体験するサイト。

## 体験の核

- 作品を一覧で眺めるのではなく、空間の中を歩き回りながら発見する
- オブジェクトごとに異なるインタラクション・演出・カメラが起きる
- 寄り込み後に詳細（作品情報・動画・クレジットなど）をモーダルで開き、閉じると探索へ戻る
- 時間経過や状況に応じた演出・BGM / 環境音で世界観を重ねる
- ローディング完了後にスタートし、メニュー・ヘルプ・設定・スタート地点復帰で迷わず探索できる

## 技術コンセプト

- **Vue 3**：UI・画面状態（ローディング / スタート / メニュー / 設定 / ヘルプ / モーダル）
- **Three.js**：3D描画・カメラ・当たり判定・演出
- **Pinia**：Vue と Three.js をつなぐ共有状態
- **データ駆動**：オブジェクト定義は `src/data/objects.js` に集約し、作品・インタラクション・演出追加の影響範囲を小さくする
