## 3-2-3. ObjectInfoPanel（モーダル枠・5.10）

### 役割

- モーダル画面の表示枠（要件 5.10）
- `whichModalSelected` に応じた作品詳細パネル（要件 5.2）
- 現状: 2002→SubComponent2 … 2006→SubComponent6

### 表示条件

```text
isModalOpen === true
かつ whichModalSelected が 2001 / 2007 以外
```

2001・2007 はカメラのみ（5.5 / 5.6 の一例）。

オーバーレイは半透明グレー（`rgba(0,0,0,0.28)`）。左側は `pointer-events: none` で 3D / スクリーン UI 操作を通し、右側 `info-panel` のみ操作可能。

## 3-2-8. サウンド関連（実装済）

### AmbientAudio（5.3）

パス: `components/audio/AmbientAudio.vue`

- 責務: 環境音の再生 / 停止 / ループ / Store 連動音量
- 定義: `data/ambientSounds.js`（現状 `ocean` = 波の音）
- 開始: ページロードでは鳴らさず、サイト上の**初回 `pointerdown`** で `play()`
- Store は `play()` / `pause()` を直接呼ばない（再生はコンポーネント側）

### ScreenVideo（5.2 / 5.3）

パス: `components/sound/ScreenVideo.vue`

- 責務: `objects.js` id:3001 のメタデータから VideoTexture 平面を生成し、表示・操作 UI を担当
- UI: `YoutubeControls` を再利用（画面下部。ホバーでフェードイン、再生中は維持）
- 操作: `useScreenVideoControls`（Raycaster クリックで再生 / 一時停止）
- `isVideoPlaying` を Store に同期。外部から `false` にされたら `pause()`

### SoundSetting（5.10 / 5.11）

パス: `components/ui/SoundSetting.vue`

- 左上ハンバーガー常設 → 左からスライドする SOUND パネル
- Master / Environment / Screen(video) 音量スライダー（Master を大きめ表示）
- `soundStore` の `masterVolume` / `environmentVolume` / `videoVolume` と双方向同期

## 3-2-9. 追加予定コンポーネント

### LoadingOverlay（5.8）

アセット読込進捗。完了まで探索開始をゲート。

### StartPage

読込完了後の開始導線。

### MenuPanel（5.10）

メニュー表示。ヘルプ・クレジット等への入口（音量は `SoundSetting` で提供済）。

### HelpPanel（5.10）

操作方法の確認。

### ExploreAssist（5.7）

探索を補助する情報（ヒント等）。Help とは別（操作説明 vs 空間内補助）。

### Effect 関連（5.9）

専用 Vue が不要な場合もある。再生制御は Three / Sound モジュール側が主で、必要なら演出中オーバーレイを UI に置く。
