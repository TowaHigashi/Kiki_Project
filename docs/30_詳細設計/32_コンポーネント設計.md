## 3-2-1. SceneCanvas（`components/three/SceneCanvas.vue`）

### 役割

- Three.js の初期化（Scene / Renderer / Camera / Light / Controls）
- アニメーションループの開始
- `InteractionManager` / `CameraController2` / `useStrollingDetection` の接続
- `SceneObject` と `ObjectInfoPanel` の配置
- `sceneStore.camera` / `controls` の登録
- （将来）アセット読込進捗の集約と Store 通知

### 表示条件

常時表示（画面全体）。ローディング導入後は「読込完了後に操作可能」とする。

### 利用 Composable / モジュール

- `useThreeScene` / `useRenderer` / `useCamera` / `useLight`
- `useOrbitControls` / `useMouse` / `useAnimationFrame`
- `useInteractionManager` / `useCameraController2` / `useCameraBlurrer`
- `useStrollingDetection`

## 3-2-3. ObjectInfoPanel（モーダル本体 UI）

### 役割

- `whichModalSelected` に応じた詳細パネルの動的表示
- 現状のマッピング: 2002→b / 2003→c / 2004→d / 2005→e / 2006→f
- （将来）外部サイト・SNS・動画埋め込み（要件 5.2 / 5.4）

### 表示条件

```text
isModalOpen === true
かつ whichModalSelected が 2001 / 2007 以外
```

2001・2007 はカメラフォーカスのみ行い、情報パネルは出さない（オブジェクト別インタラクションの一例）。
