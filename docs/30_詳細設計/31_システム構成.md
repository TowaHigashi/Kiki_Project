## Three.js 主要モジュール

| モジュール | ファイル | 責務 | 要件 |
|------------|----------|------|------|
| シーン生成 | `useThreeScene.js` | `THREE.Scene` | 5.1 |
| レンダラ | `useRenderer.js` | `WebGLRenderer` | 5.1 |
| カメラ生成 | `useCamera.js` | 初期は objects id:1001 | 5.6 |
| ライト | `useLight.js` | Directional + Ambient | — |
| 操作 | `useOrbitControls.js` | OrbitControls | 5.1 |
| カメラ移動 | `CameraController2.js` | `moveCamera` / `update` | 5.6 |
| クリック | `InteractionManager.js` | drag + Raycaster + Store | 5.5 |
| 当たり判定 | `useRaycaster.js` | `intersectObjects` | 5.5 |
| 散策判定 | `useStrollingDetection.js` | 距離 → `isUserStrolling` | 5.6 |
| スクリーン操作 | `useScreenVideoControls.js` | 動画メッシュの click / hover | 5.2 / 5.3 |
| 演出（将来） | （未定） | 時間 / オブジェクト演出 | 5.9 |

旧 `CameraController.js` は廃止予定。

### CameraController2 公開 API

| メソッド | 内容 |
|----------|------|
| `moveCamera(position, target)` | Store の lerp 目標をセット |
| `update()` | 毎フレーム lerp。移動中は controls を無効化 |

### Raycaster

- 公開: `cast({ mouse, camera, objects })`
- Hover はスクリーン動画向けに `useScreenVideoControls` で利用

## サウンドモジュール（実装済・5.3 / 5.11）

| モジュール | ファイル | 責務 |
|------------|----------|------|
| 状態 | `stores/soundStore.js` | 音量 / Duck / 再生フラグ |
| 環境音定義 | `data/ambientSounds.js` | 環境音メタデータ（拡張用 source / position 含む） |
| 環境音再生 | `components/audio/AmbientAudio.vue` | `<audio>` ループ・Store 連動 |
| スクリーン動画 | `components/sound/ScreenVideo.vue` | VideoTexture + 独自 UI |
| 音量 UI | `components/ui/SoundSetting.vue` | ハンバーガー + 左スライドパネル |

### 音量計算（現状）

| 対象 | 式 |
|------|-----|
| 環境音 | `masterVolume × masterDucker × environmentVolume × environmentDucker` |
| スクリーン動画 | `masterVolume × videoVolume`（`videoEnabled` / mute 時は 0） |

### Duck（現状）

| 条件 | 効果 |
|------|------|
| `isVideoPlaying` または `isYoutubePlaying` | `environmentDucker` を減衰値へ（Environment Duck ON） |
| 上記いずれも false | `environmentDucker = 1.0`（OFF） |

YouTube 再生開始時は `isYoutubePlaying = true` かつ `isVideoPlaying = false`（スクリーン動画を停止）。停止 / 終了で Duck OFF。スクリーンの自動再開はしない。
