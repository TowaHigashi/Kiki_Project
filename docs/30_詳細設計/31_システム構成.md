## レイヤー連携

```text
[ユーザー操作]
     │
     ├─ pointer / click ──► InteractionManager ──► Raycaster
     │                              │
     │                              ├─ objects.js 検索
     │                              ├─ インタラクション種別で分岐（将来）
     │                              ├─ CameraController2.moveCamera
     │                              └─ sceneStore 更新
     │
     ├─ UI ボタン ─────────► sceneStore / CameraController2
     │
     └─ 毎フレーム ────────► CameraController2.update
                            OrbitControls.update
                            useStrollingDetection.update
                            renderer.render
```

```text
sceneStore
  ├── Vue UI（表示条件・選択 ID・将来の loading / start / help）
  └── Three.js（camera / controls / lerp 目標）
```

Vue と Three.js は **Store 経由のみ**で状態を共有する（設計方針どおり）。

## Three.js 主要モジュール

| モジュール | ファイル | 責務 |
|------------|----------|------|
| シーン生成 | `useThreeScene.js` | `THREE.Scene` |
| レンダラ | `useRenderer.js` | `WebGLRenderer` |
| カメラ生成 | `useCamera.js` | `PerspectiveCamera`（初期は objects id:1001） |
| ライト | `useLight.js` | Directional + Ambient |
| 操作 | `useOrbitControls.js` | OrbitControls |
| カメラ移動 | `CameraController2.js` | `moveCamera` / 毎フレーム `update`（lerp） |
| クリック | `InteractionManager.js` | drag 判定 + Raycaster + Store 更新 |
| 当たり判定 | `useRaycaster.js` | `intersectObjects(..., true)` |
| 散策判定 | `useStrollingDetection.js` | 初期位置からの距離 → `isUserStrolling` |

旧 `CameraController.js` は廃止予定。新規実装は `CameraController2` を使う。

### CameraController2 公開 API

| メソッド | 内容 |
|----------|------|
| `moveCamera(position, target)` | Store の `targetPosition` / `targetLookAt` をセット |
| `update()` | 毎フレーム lerp。移動中は controls を無効化 |

### Raycaster

- 公開: `cast({ mouse, camera, objects })`
- Hover 判定は現状未実装（クリック判定のみ）
