# 3-8. エラー処理

## 方針

- ユーザー向けには状況を壊さず伝える（とくにローディング中）
- 開発時は `console` に原因を残す
- 1 オブジェクトの失敗でシーン全体を落とさない
- 必須アセット失敗時は探索開始ゲート（5.8）を通さない、または縮退起動を明示する

---

## 対象と現状 / 想定対応

| ケース | 現状 | 想定対応 | 要件 |
|--------|------|----------|------|
| GLB 読込失敗 | 未統一 | 該当のみスキップ + ログ + ローディング集計へ通知 | 5.8 |
| 必須アセット失敗 | ゲートなし | 再試行 / エラー表示。探索開始不可 | 5.8 |
| 任意アセット失敗 | 同上 | 欠落のまま開始可 | 5.8 |
| モデルパス不正 | 欠落して見える | `public/models` との対応確認 | — |
| id 重複 / 欠落 | 誤動作 | 開発時チェック | — |
| `interaction` 未定義 | — | デフォルト動作にフォールバック | 5.5 |
| `effect` 未定義 / 再生失敗 | — | 演出スキップ + ログ。探索は継続 | 5.9 |
| `cameraFocusIn` 空のクリック | モーダル非表示 | 仕様として許容 | 5.5 / 5.6 |
| 動画・外部リンク失敗 | YouTube は実装済。Player 生成失敗時は console | 埋め込み失敗時のユーザー向け代替 UI は未整備 | 5.2 / 5.4 |
| BGM / 環境音読込失敗 | 環境音は実装済 | 読込失敗時は無音継続・console 警告。トグル無効化は未 | 5.3 / 5.9 |
| 音量・設定の永続化失敗 | 未実装（サイト設定はセッション内） | デフォルト値で継続。`SoundSetting` は永続化なし | 5.11 |
| フルスクリーン拒否 / 失敗 | 未実装 | UI で失敗を伝え、状態を戻す | 5.11 |
| WebGL 非対応 | 未処理 | DOM に非対応メッセージ | 6.1 |
| テクスチャ / HDR 失敗 | 未整備 | フォールバック色・環境光 | — |

---

## ローディングとの関係（5.8）

```text
読込エラー
  ├─ 必須失敗 → 開始不可 + エラー / 再試行
  └─ 任意失敗 → 警告ログ → Start / Explore へ
```

必須 / 任意はデータまたはローダー設定で定義する。
