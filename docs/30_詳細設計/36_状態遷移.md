# 3-6. 状態遷移

本システムに正式なステートマシンライブラリは使わない。  
`sceneStore` のフラグ組み合わせで論理状態を表現する。

---

## 論理状態

### 目標（要件対応後）

| 状態名 | 概要 | 要件 |
|--------|------|------|
| **Loading** | アセット読込中。探索不可 | 5.8 |
| **Start** | 開始導線 | シナリオ |
| **Explore** | 探索（初期位置付近） | 5.1 |
| **Strolling** | 初期位置から離れた探索 | 5.6 |
| **Modal** | モーダル（作品詳細） | 5.10 / 5.2 |
| **Effect** | 演出再生中 | 5.9 |
| **Menu** | メニュー表示 | 5.10 |
| **Settings** | 音量設定（SoundSetting）/ 将来の詳細設定 | 5.10 / 5.11 |
| **Help** | ヘルプ表示 | 5.10 |

Menu / Settings / Help は Explore / Strolling 上のオーバーレイとして重ねてよい。

### 現状（実装済）

| 状態名 | 条件 | できること |
|--------|------|------------|
| **Explore** | `isModalOpen === false` かつ初期位置付近 | 見回す / クリック / 環境音・スクリーン操作 |
| **Strolling** | `isUserStrolling === true` | BackButton1 で初期位置へ |
| **Modal** | `isModalOpen === true` | CLOSE / 左右スライド。左はグレー透過でスクリーン操作可 |
| **Settings（音量）** | `SoundSetting` パネル開 | Master / Environment / Screen 音量変更 |

Loading / Start / 汎用 Menu / Help / Effect は **未実装**。

---

## 遷移図（目標）

```text
[起動] → Loading → Start → Explore ⇄ Strolling
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
           Modal           Effect      Menu/Settings/Help
              │               │               │
              └───────────────┴───────────────┘
                              │ 閉じる / 完了
                              ▼
                           Explore / Strolling
```

Strolling → BackButton1 → Explore（初期位置）。

### 遷移図（現状）

```text
[起動] → Explore ⇄ Strolling
              │
              ▼
            Modal ⇄（左右で id のみ）
              │ CLOSE
              ▼
         Explore / Strolling
```

---

## フラグ遷移表（現状）

| きっかけ | isModalOpen | whichModalSelected | isUserStrolling |
|----------|-------------|--------------------|-----------------|
| 起動時 | `false` | `''` | `false` |
| オブジェクトクリック | `true` | 対象 id | `false` |
| 左右スライド | `true` | 遷移先 id | `false` |
| CLOSE | `false` | `null` | 距離で再計算 |
| 初期位置から離れる | `false` | — | `true` |
| BackButton1 | `false` | — | 復帰後 `false` |

導入後は `isAssetsReady` / `hasStarted` / `isMenuOpen` 等をゲート・排他に使う（`33_Store設計.md`）。
