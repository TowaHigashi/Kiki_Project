# 3-6. 状態遷移

本システムに正式なステートマシンライブラリは使わない。  
`sceneStore` のフラグ組み合わせで論理状態を表現する。

---

## 論理状態

### 目標（要件対応後）

| 状態名 | 概要 | 要件 |
|--------|------|------|
| **Loading** | アセット読込中。探索不可 | 5.8 |
| **Start** | 開始導線表示 | シナリオ |
| **Explore** | 探索可能（初期位置付近） | 5.1 |
| **Strolling** | 初期位置から離れた探索 | 5.6 / 5.7 |
| **Modal** | オブジェクトフォーカス / 詳細閲覧 | 5.2 |
| **Effect**（任意） | オブジェクト別演出再生中 | 5.5 / 5.6 |

### 現状（実装済）

| 状態名 | 条件 | ユーザーができること |
|--------|------|----------------------|
| **Explore** | `isModalOpen === false` かつ初期位置付近 | OrbitControls / オブジェクトクリック |
| **Strolling** | `isModalOpen === false` かつ `isUserStrolling === true` | BackButton1 で初期位置へ戻れる |
| **Modal** | `isModalOpen === true` | CLOSE / 左右スライド |

Loading / Start は **未実装**（起動直後は Explore）。

---

```text
                 [アプリ起動]
                      │
                      ▼
                ┌──────────┐
                │ Loading  │

                     │ 読込完了
                     ▼
                ┌──────────┐
                │  Start   │── 開始 ──┐
                └──────────┘         │
                                     ▼
                               ┌───────────┐
                               │  Explore  │◄──────────────────────┐
                               └─────┬─────┘                       │
                                     │                             │
                     カメラが初期位置から離れる                      │
                                     │                             │
                                     ▼                             │
                               ┌───────────┐                       │
                               │ Strolling │── BackButton1 ────────┤
                               └─────┬─────┘                       │
                                     │                             │
                     インタラクション（種別による）                   │
                                     │                             │
                          ┌──────────┼──────────┐                  │
                          ▼          ▼          ▼                  │
                      [Modal]    [Effect]  [その他]                 │
                          │          │          │                  │
                          └──────────┴──────────┘                  │
                                     │ 完了 / CLOSE                │
                                     └─────────────────────────────┘
```

### 遷移図（現状）

```text
[起動] → Explore ⇄ Strolling
              │
              ▼
            Modal ⇄（左右で id のみ変化）
              │ CLOSE
              ▼
            Explore / Strolling
```

---

## フラグ遷移表（現状）

| きっかけ | isModalOpen | whichModalSelected | isUserStrolling |
|----------|-------------|--------------------|-----------------|
| 起動時 | `false` | `''` | `false` |
| オブジェクトクリック | `true` | 対象 id | `false`（強制） |
| 左右スライド | `true`（維持） | 遷移先 id | `false` |
| CLOSE | `false` | `null` | 距離に応じて再計算 |
| 初期位置から離れる | `false` | （変更なし） | `true` |
| BackButton1 | `false` | （変更なし） | 復帰後に `false` へ |

Loading / Start 導入後は `isAssetsReady` / `hasStarted` をゲート条件に追加する（`33_Store設計.md`）。

## Three.js 側の補足状態

カメラ移動中は `targetPosition` / `targetLookAt` が非 null となり、`CameraController2.update` が OrbitControls を無効化する。  
到達（距離 < 0.005）で目標をクリアし、操作を復帰する。
