# 3-7. 画面遷移

## 想定フロー（要件）

```text
Loading（アセット読込）
  │
  ▼
Start
  │
  ▼
Scene（探索）
  │
  ▼
Modal / オブジェクト別インタラクション
  │
  ▼
Scene
```

※ SPA（Single Page Application）。vue-router は使用しない。  
※ 「画面」は URL 遷移ではなく、同一 View 上の **論理モード切替**（`36_状態遷移.md`）。

---

## 実装状況

| 画面 | 実装 | 実装上の表現 | 要件 |
|------|------|----------------|------|
| Loading | **未実装** | なし（読込完了を待たず描画開始） | 5.8 |
| Start | **未実装** | なし（起動直後に Scene） | シナリオ |
| Scene | **実装済** | `MainView` + `SceneCanvas` + OrbitControls | 5.1 |
| Modal | **実装済** | `isModalOpen` + `ObjectInfoPanel` + CLOSE / スライド | 5.2 |
| Help / ナビ補助 | **一部** | BackButton1（スタート地点復帰）のみ | 5.7 |

---

## Modal 内のコンテンツ切替

Modal 中は左右ナビにより、別オブジェクトのフォーカスへ切り替わる（Scene に戻らない）。

```text
Modal(id=2002) ⇄ Modal(id=2003) ⇄ … ⇄ Modal(id=2007)
```

遷移先は `modalComponentMap.js` で定義する。

オブジェクト別インタラクション（要件 5.5）が Modal 以外を取る場合は、Scene 上で演出のみ再生して戻る、などの分岐を `35_イベント設計.md` に従う。
