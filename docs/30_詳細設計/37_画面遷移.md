# 3-7. 画面遷移

## 想定フロー（要件）

```text
Loading（5.8）
  │
  ▼
Start（シナリオ）
  │
  ▼
Scene（探索・5.1）
  │
  ├── Modal（5.10 枠 / 5.2 中身）
  ├── Effect（5.9）
  ├── Menu / Settings / Help / Credits（5.10 / 5.11）
  └──（閉じる・完了後）Scene へ戻る
```

※ SPA。vue-router なし。論理モード切替（`36_状態遷移.md`）。
