# 3-5. イベント設計

本システムの体験フローはイベント単位で定義する。  
データファイル名は実装どおり **`objects.js`**。

---

## 3-5-1. オブジェクトクリック（現状：モーダル / カメラ）

```text
pointerdown / pointermove / click
    │
    ▼
InteractionManager（drag 閾値 5px 超なら無視）
    │
    ▼
useRaycaster.cast
    │
    ▼
hit mesh の userData.id 取得
    │
    ▼
objects.js から該当エントリ検索
    │
    ▼
cameraFocusIn.position が有効？
    │ いいえ → 何もしない（装飾モデルなど）
    │ はい
    ▼
CameraController2.moveCamera(focusIn)
    │
    ▼
Store: isModalOpen = true
       whichModalSelected = id
    │
    ▼
UI: BackButton2 / SlideBottun 表示
    ObjectInfoPanel（2002–2006 のみ）表示
```

将来は検索後に `interaction` 種別で分岐する（要件 5.5）。例:

- `openModal` … 現状フロー
- `cameraOnly` … カメラ移動のみ（2001 / 2007 相当）
- `playEffect` … 演出再生
- `externalLink` … 外部遷移（5.2 / 5.4）

---

## 3-5-2. モーダルを閉じる

```text
BackButton2 クリック
    │
    ▼
Store: isModalOpen = false
    │
    ▼
objects.js から whichModalSelected のエントリ検索
    │
    ▼
CameraController2.moveCamera(cameraFocusOut)
    │
    ▼
Store: whichModalSelected = null
    │
    ▼
UI: モーダル系 UI 非表示 → 探索へ復帰
```

---

## 3-5-3. モーダル内の左右移動

```text
SlideBottun 左右クリック
    │
    ▼
modalComponentMap から遷移先 id 取得
    │
    ▼
objects.js で遷移先の cameraFocusIn 取得
    │
    ▼
CameraController2.moveCamera(focusIn)
    │
    ▼
Store: whichModalSelected = 遷移先 id
（isModalOpen は true のまま）
```

---

## 3-5-4. 散策検知（初期位置から離れる）

```text
毎フレーム（animation loop）
    │
    ▼
useStrollingDetection.update
    │
    ├─ isModalOpen === true
    │     → isUserStrolling = false（強制）
    │
    └─ カメラ位置と id:1001 の距離 > threshold(2)
          → isUserStrolling = true
          → BackButton1 表示
```

---

## 3-5-5. 初期位置 / スタート地点へ戻る（要件 5.6 / 5.7）

```text
BackButton1 クリック
    │
    ▼
objects.js の id:1001（position / target）を取得
    │
    ▼
Store: targetPosition / targetLookAt をセット
    │
    ▼
CameraController2.update が lerp で復帰
```

---

## 3-5-6. カメラ移動の更新（共通）

```text
毎フレーム
    │
    ▼
CameraController2.update
    │
    ├─ target あり → controls 無効化しながら lerp
    └─ target なし → controls / damping を復帰
```

状況に応じたカメラ演出バリエーション（要件 5.6）は未実装。将来は `cameraMotion` 等で差し替える。
