# 3-5. イベント設計

本システムの体験フローはイベント単位で定義する。  
データファイルは **`objects.js`**。要件番号は `10_要件定義.md` の 5.1〜5.11 に対応する。

---

## 3-5-1. オブジェクトクリック（現状：モーダル / カメラ）

```text
pointerdown / pointermove / click
    │
    ▼
InteractionManager（drag 閾値 5px 超なら無視）
    │
    ▼
useRaycaster.cast → userData.id → objects.js 検索
    │
    ▼
cameraFocusIn.position が有効？
    │ いいえ → 何もしない
    │ はい
    ▼
CameraController2.moveCamera(focusIn)（5.6）
    │
    ▼
Store: isModalOpen = true / whichModalSelected = id（5.10 / 5.2）
    │
    ▼
UI: BackButton2 / SlideBottun / ObjectInfoPanel（2002–2006）
```

将来は `interaction` で分岐（5.5）。例:

- `openModal` … 現状
- `cameraOnly` … カメラのみ（2001 / 2007）
- `playEffect` … 演出再生（5.9）
- `externalLink` … 外部遷移（5.2 / 5.4）

## 3-5-10. 環境音（5.3）【実装済】

```text
ページ表示
  → AmbientAudio マウント（再生はしない）
  → ユーザー初回 pointerdown

```

---

## 3-5-11. スクリーン動画（5.2 / 5.3）【実装済】

```text
メッシュ hover → ScreenVideo UI 表示（フェード）
メッシュ click → play / pause
  → isVideoPlaying = true/false
  → Environment Duck ON/OFF（soundStore watch）

YouTube PLAYING
  → isYoutubePlaying = true（Environment Duck ON）
  → isVideoPlaying = false → ScreenVideo pause

YouTube PAUSED / ENDED
  → isYoutubePlaying = false（Environment Duck OFF）
  → スクリーン自動再生はしない
```
