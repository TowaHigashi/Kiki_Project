# 詳細設計

## 概要

本プロジェクトの詳細設計は、**コンポーネント単位ではなくイベント単位**で整理する。

Vue コンポーネントや Store は、開発の進行に伴って分割・統合される可能性がある。一方で、「ユーザーがクリックして作品を閲覧する」といった体験の流れは、大きく変更される可能性が低い。

そのため、本設計書ではイベントフローを中心とし、その中で

- どのコンポーネントが担当するか
- どの Store を更新するか
- どの Composable が処理を担当するか

を対応付けて記載する。

要件の正本は [`10_要件定義.md`](../10_要件定義.md)。各詳細設計は要件 **5.1〜5.11** および実装状況（§7）と対応させる。
