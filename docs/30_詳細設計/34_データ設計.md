# 3-4. データ設計

## 概要

静的設定は `src/data/` に集約する。

| ファイル | 役割 |
|----------|------|
| `objects.js` | カメラ設定・クリック判定・装飾モデル・（将来）インタラクション定義 |
| `modalComponentMap.js` | モーダル表示中の左右オブジェクト遷移 |

要件 5.5 / 5.6 の「オブジェクトごとに異なる動作・カメラ演出」は、可能な限り本データ層で表現する。

---

## 1. `objects.js`（`Objects` 配列）

### フィールド定義（実装済）

| フィールド | 内容 | 備考 |
|------------|------|------|
| `type` | `'config'` \| `'object'` | 分類用。現状ロジック分岐には未使用 |
| `fileName` | GLB ファイル名 | config は空文字 |
| `path` | 公開パス（例: `/models/xxx.glb`） | `public/models/` 配下を想定 |
| `position` | `[x, y, z]` または `''` | 配置 / カメラ初期位置 |
| `rotation` | `[x, y, z]` または `''` | ラジアン |
| `scale` | `[x, y, z]` または `''` | |
| `target` | `[x, y, z]` または `''` | config（id:1001）の初期注視点 |
| `invisible` | `boolean` \| `''` | `true` で透明クリックメッシュ |
| `name` | 表示用・管理用名称 | プログラム上は未使用 |
| `id` | 数値 ID | mesh の `userData.id` に載せる |
| `cameraFocusIn` | `{ position, target }` | 寄るときのカメラ。空ならクリックしてもモーダルを開かない |
| `cameraFocusOut` | `{ position, target }` | 閉じるときのカメラ |

### 追加予定フィールド（要件 5.5 / 5.6）

| フィールド（案） | 内容 | 例 |
|------------------|------|----|
| `interaction` | クリック時アクション種別 | `'openModal'` / `'cameraOnly'` / `'playEffect'` / `'externalLink'` など |
| `effect` | 演出パラメータ | アニメ名・SE・パーティクル等の参照 |
| `cameraMotion` | カメラ演出の種別・秒数 | `'lerp'` / `'orbit'` など（現状は一律 lerp） |
| `panel` / `links` | 紐づく UI・外部 URL | 動画 URL、SNS URL（5.2 / 5.4） |

現状は `cameraFocusIn` の有無と `ObjectInfoPanel` の id 分岐で実質的に種別を分けている。  
拡張時は上記をデータ化し、`InteractionManager` の分岐をデータ参照に寄せる。

### ID 採番ルール

| 帯 | 用途 | 例 |
|----|------|----|
| `1xxx` | カメラ等の config | `1001` 初期カメラ |
| `2001`〜`2007` | クリック判定オブジェクト | モーダル遷移対象 |
| `21xx` | 装飾用 3D モデル | `2101`〜`2104`。`cameraFocusIn` が空のため単体クリックではモーダル非表示 |

### 現状のオブジェクトとモーダル対応

| id | name | 実質のインタラクション | モーダルパネル |
|----|------|------------------------|----------------|
| 2001 | クリック判定1 | カメラのみ | なし |
| 2002 | クリック判定2 | カメラ + モーダル | `SubComponent2.vue` |
| 2003 | クリック判定3 | カメラ + モーダル | `SubComponent3.vue` |
| 2004 | クリック判定4 | カメラ + モーダル | `SubComponent4.vue` |
| 2005 | クリック判定5 | カメラ + モーダル | `SubComponent5.vue` |
| 2006 | クリック判定6 | カメラ + モーダル | `SubComponent6.vue` |
| 2007 | クリック判定7 | カメラのみ | なし |
| 2101–2104 | 装飾モデル | なし（クリック無効相当） | — |

## 2. `modalComponentMap.js`

モーダル中の左右ナビ用。キーはオブジェクト `id`。

```js
{
  2001: { left: 2007, right: 2002 },
  // … 2002〜2006 …
  2007: { left: 2006, right: 2001 },
}
```

`SlideBottun` が参照し、遷移先の `cameraFocusIn` へカメラを移動したうえで `whichModalSelected` を更新する。

---

## 3. mesh `userData`

`SceneObject.vue` が GLB 読み込み後、各 mesh にメタデータをコピーする。  
`InteractionManager` はヒットした mesh の `userData.id` から `Objects` を検索する。

---

## 4. ローディング対象（要件 5.8）

読込ゲートの対象は、少なくとも `Objects` のうち `path` が空でないエントリの GLB とする。  
進捗集計の実装時は、本配列をソース・オブ・トゥルースにする。
