# 3-4. データ設計

## 概要

静的設定は `src/data/` に集約する。

| ファイル | 役割 |
|----------|------|
| `objects.js` | 配置・カメラ・インタラクション・スクリーン動画メタ・（将来）演出参照 |
| `ambientSounds.js` | 環境音定義（5.3） |
| `modalComponentMap.js` | モーダル左右遷移 |

要件との対応:

- 5.5 インタラクション種別 → データ化
- 5.6 カメラ演出 → `cameraMotion` 等
- 5.3 環境音 → `ambientSounds.js`
- 5.9 オブジェクト / 時間演出・BGM 切替 → `effect` / 演出テーブル
- 5.8 ローディング対象 → `path` のあるエントリ

---

## 1. `objects.js`（`Objects` 配列）

### フィールド定義（実装済）

| フィールド | 内容 | 備考 |
|------------|------|------|
| `type` | `'config'` \| `'object'` \| `'video'` | 分類用。動画は `'video'` |
| `fileName` / `path` | GLB または動画パス | `public/models/` / `public/video/` |
| `position` / `rotation` / `scale` | 配置 | |
| `target` | 初期注視点 | id:1001 |
| `invisible` | 透明クリックメッシュ | |
| `name` / `id` | 管理名・数値 ID | `userData.id` |
| `cameraFocusIn` / `cameraFocusOut` | 寄る / 戻るカメラ | 空ならモーダル非オープン |

### 追加予定フィールド

| フィールド（案） | 要件 | 内容 |
|------------------|------|------|
| `interaction` | 5.5 | `'openModal'` / `'cameraOnly'` / `'playEffect'` / `'externalLink'` など |
| `effect` | 5.9 | オブジェクト応じた演出の参照 |
| `cameraMotion` | 5.6 | カメラ演出種別・秒数 |
| `panel` / `links` | 5.2 / 5.4 | パネル・外部 URL |
| `hint` | 5.7 | 探索補助テキスト等 |

現状は `cameraFocusIn` の有無と `ObjectInfoPanel` の id 分岐で種別を分けている。`type: 'video'` は `InteractionManager` でスキップし `useScreenVideoControls` が扱う。

### ID 採番

| 帯 | 用途 |
|----|------|
| `1xxx` | config（例: 1001 初期カメラ） |
| `2001`〜`2007` | クリック判定 |
| `21xx` | 装飾モデル |
| `30xx` | スクリーン動画（例: 3001） |

### 現状のオブジェクト対応

| id | 実質のインタラクション | モーダル |
|----|------------------------|----------|
| 2001 / 2007 | カメラのみ | なし |
| 2002〜2006 | カメラ + モーダル | `SubComponent2`〜`6` |
| 2101–2104 | なし | — |
| 3001 | スクリーン動画再生 | なし（`ScreenVideo`） |

## 4. 環境音メタデータ（`ambientSounds.js`・実装済）

| フィールド | 内容 |
|------------|------|
| `id` | 一意 ID（例: `ocean`） |
| `src` | `public` 配下パス |
| `type` | `'environment'` |
| `loop` | ループ再生 |
| `source` | 将来: 発生源キー（現状未使用） |
| `position` | 将来: `{ x, y, z }`（現状未使用・音量計算には未使用） |

現状 1 件（波の音 `/audio/ambient/VSQSE_1046_wave_28.mp3`）。追加時はこの配列にエントリを足す。

---

## 5. YouTube メタデータ（`SubComponent5/youtubeData.js`・実装済）

`objects.js` には置かず、SubComponent5 配下で完結する。

| フィールド | 内容 |
|------------|------|
| `url` → `videoId` | YouTube URL から ID 抽出 |
| `title` | 動画タイトル |
| `description.DATE` 等 | DATE / TYPE / CONCEPT / CREDIT / COMMENT（各配列） |

現状 3 本（女郎蜘蛛 / パンドラ / 爪痕）。description 文言は一部仮。

---

## 6. 演出データ（要件 5.9・将来）

オブジェクト横断の定義は、`objects.js` 内に持たせるか、別ファイル（例: `effects.js` / `timelines.js`）に分離する。

| 種別 | 内容 |
|------|------|
| 時間経過演出 | 経過秒やシーン状態をトリガにするタイムライン |
| オブジェクト演出 | `effect` 参照先（アニメ / パーティクル / SE） |
| BGM 状況切替 | 状態（Explore / Modal / 特定エリア）→ トラック ID |

---

## 7. ローディング対象（要件 5.8）

少なくとも `path` が空でない GLB。進捗集計時は本配列をソース・オブ・トゥルースにする。  
環境音（`ambientSounds.js`）・スクリーン動画（id:3001）もゲート対象に含める場合は一覧を明示する。
